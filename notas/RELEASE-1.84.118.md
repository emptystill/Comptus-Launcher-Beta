# Comptus 1.84.118

## Imágenes de SteamGridDB para juegos nuevos o renombrados
- Antes las imágenes solo se buscaban **al abrir Comptus**. Si un juego no se encontraba, no se volvía a intentar en dos semanas, aunque le cambiaras el nombre.
- Ahora se buscan **al momento** cuando aparece un juego nuevo (por ejemplo, uno añadido a mano).
- Si le cambias el nombre a un juego, se vuelve a buscar con el nombre nuevo.
